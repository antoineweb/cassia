How to write a request that gets done right the first time
  1. Say where. Name the part of the page and the exact item, for example "Products, Powder card" or "Promises, Halal certificate".
  2. Quote what is there now. Copy the current wording so there is no doubt which text you mean.
  3. Give the exact new version. Write the final text, number or link as it should appear, spelling and capitals included.
  4. One change per request. Three small requests are faster to handle than one long message.
  5. For a photo or logo, say which one to replace and where the new file is. This page cannot receive files.
  6. For a display problem, say phone or computer, and what you expected to see.
